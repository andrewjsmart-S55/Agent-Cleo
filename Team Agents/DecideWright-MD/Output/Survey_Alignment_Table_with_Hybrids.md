## HYBRID SURVEY BENEFITS

### Why Hybrid Approach?

1. **Balanced Perspective**: Combines subjective risk assessment with objective metrics
2. **Validation**: Scale ratings can be validated against actual data
3. **Flexibility**: Organizations can start with scale, add data as it becomes available
4. **Richer Analysis**: Multiple data points enable more sophisticated risk modeling
5. **Comparability**: Scale allows benchmarking even when exact metrics differ

### Recommended Hybrid Implementation

**Initial Survey (Hybrid)** - Time: ~30-40 minutes
- Answer both scale (1-5) and 2-3 key metrics per question
- Company-wide view
- Best for: Quick assessment with data backing

**Detailed Survey (Hybrid)** - Time: Variable by region
- Answer both scale and metrics for each region
- Full regional granularity
- Best for: Comprehensive risk mapping with maximum precision

### Data Collection Guidance

**Scale Questions (1-5)**:
- Based on informed judgment
- Consider trends, not just current state
- Aggregate view of the risk

**Numeric Metrics**:
- Use actual data where available
- Estimate if precise data not accessible
- Focus on trends and directional accuracy
- Can be refined over time
